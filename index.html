2. 분석 결과

⚠ 계산 방식에 대한 안내
- 길이, GC 함량, Wallace rule Tm, 결합 위치, PCR 산물 길이 계산은 결정론적 로직으로 정확하게 계산됩니다.
- Tm(열역학적 계산)은 SantaLucia의 Nearest-Neighbor 열역학 파라미터를 이용해 브라우저 JavaScript로 직접 구현한 근사 계산이며, Python 버전(Primer3-py)과 완전히 동일한 수치가 아닐 수 있습니다.
- Hairpin / Self-dimer / Heterodimer는 Primer3-py와 같은 완전한 열역학적 폴딩 계산이 아니라, 상보 염기쌍이 연속으로 일치하는 구간을 찾는 간이 알고리즘(참고용)입니다. ΔG(자유에너지) 값이 아니라 "연속 상보 염기쌍 길이"로 구조 형성 가능성만 참고용으로 표시합니다.
- 이 결과는 일반적인 설계 가이드라인과의 비교일 뿐이며, 실제 PCR 실험의 성공 여부를 보장하지 않습니다.
